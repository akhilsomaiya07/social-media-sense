# Sleep Shield

Sleep Shield is an optional dedicated tool opened from My Tools, not an assessment step. It does not alter a completed report. Step 3 retains duration, age-related context and pre-bed social-media questions; clock time is required only to activate a plan.

Existing wind-down choices, midnight calculations, replacement/custom activities, one-night forms, notes, saved-night editing, comparisons and confirmed clearing remain. Saved plans can be resumed without a new assessment. Research and projections remain collapsed disclosures.

Version-1 Sleep Shield storage is retained, including settings, activities, bedtime and nights. Older assessment bedtimes remain supported. Missing bedtime is never invented. Clearing check-ins and goals does not touch Sleep Shield records.

See [TOOLS-ARCHITECTURE.md](TOOLS-ARCHITECTURE.md) for storage details, regression commands and limitations. Production retrieval is not claimed by controlled browser fixtures.
